# Dynamic Interface

The interface MUST adapt to the authenticated user's role.

Navigation

Sidebar

Quick actions

Buttons

Menus

Widgets

Dashboard

Everything should change according to permissions.

Never show actions the user cannot execute.

Never display disabled actions caused by permissions.

Instead,

display an interface naturally designed for that role.

Users should never wonder:

"Why can I see this if I cannot use it?"
